FAQ

Why do some symbols show as an empty box (□)? The symbol is valid Unicode, but the font on your device doesn't include a glyph for it. The person you send it to may still see it correctly if their device has better font coverage.

Will a copied symbol work everywhere? Yes — these are standard Unicode characters, not images. Any app that handles text (email, chat, documents, code) can display them, subject to font support.

What's the difference between a symbol and an emoji? Both are Unicode characters. Emoji are typically rendered as colorful pictures by the operating system, while symbols render as regular text glyphs that inherit your font size and color.
